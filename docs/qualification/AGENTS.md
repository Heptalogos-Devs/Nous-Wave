# Qualification Instructions

This scope owns verification evidence for active plans and executable Specs.

- Record only commands actually run against the current checkout.
- Use `PASS`, `FAIL`, `NOT_RUN`, and `BLOCKED` consistently; preserve partial evidence and do not convert historical results into current results.
- Link evidence back to the owning plan and Spec. Do not use Qualification as a second implementation plan or architecture source.
- Update `docs/INDEX.md` when qualification records are added, renamed, or retired.
