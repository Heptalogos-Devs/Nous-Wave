# Deterministic Cognitive Structure Fixture

从旧 observatory/garden/archive 模板实验提取一条 10-event 时间线，只用于检查时间、更新、1/2/3-hop 与 hub 的确定性结构接线。许可为 CC0-1.0。

[manifest](manifest.json)、[scenario](scenarios/observatory.json)、[queries](queries.json) 与 [associations](associations.json) 保存输入与摘要。Tag 和 Association 是 host-explicit 输入；本 fixture 不证明自动 maintenance、Accretion 或真实用户检索质量。

2026-10-04 的模板实验和配对 rerank 结果降级为探索性记录，不参与本轮 Functional Validation Corpus 验收。已付费 cache、原始数据和输出保留在 ignored research root；完整 tracked 旧输入可由 Git 恢复。本轮停止原全量运行。

新的小型功能集须使用独立人工审定场景、直接 Prepared Query、自动形成的 Tag/Association 和可解释支持链，先检查形成与维护，再比较 retrieval。Text compatibility 使用独立 raw-text 条件。
