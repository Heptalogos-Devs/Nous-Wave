# Nous Wave 当前状态

## Available

- Subject/Configuration/Material foundations 与 Memory-only 能力组合。
- Memory/CognitiveSchema/Tag/AssociationEvidence Authority、不可变 revision、provenance、并发 fencing、幂等、suppression/restore/purge。
- Session residency、meaningful UseEvent、WorkContext durable checkpoint 与跨 Session continuation。
- Memory-owned Episode exact revision、history、hierarchy、track 与 lifecycle。
- QueryExpr、hard constraints、typed preferences、lexical/dense/runtime lanes、固定融合、模型 rerank 和最终 Authority revalidation。
- Gateway/ModelProfile/RoleBinding、Prompt identity、Formation reservation/replay、immutable DerivedRepresentation DAG 与 structured payload/field supports。
- optional External Resource/RAGFlow adapter、冻结 query ticket、host action/finalize/release、选用结果后形成 Observation。
- official Client、CLI、流式材料上传、trace；独立 RuntimeLocations 与 Windows x64 source-less portable assembly。

## Experimental

显式 topology lane 的 weighted PCA/residual/bounded propagation/node-potential 排序。真实 retrieval/media 研究观测见 [Research](../research/README.md)。
