# Test Value

Delete old tests when stronger current scenarios cover their failure mode. Keep distinct Authority, provenance, idempotency, lifecycle, concurrency, parser and algorithm risks. Test support stays in tests; production APIs serve product consumers.

Database tests reuse a prepared PostgreSQL runtime and own temporary clusters. Choose an owner test during iteration; `just check-fast` catches static errors and `just check` runs the ordinary suite. Core/Kernel/public protocol changes use relevant `scripts/smoke/` scenarios. Portable changes use current release verification. Live provider and corpus measurements belong to Research.
